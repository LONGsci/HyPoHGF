# HyPoHGF
HyPoHGF: Hybrid Pooling Heterogeneous Graph Fusion for Acupuncture Prescription Recommendation

This project introduces the Acudata dataset, a comprehensive acupuncture heterogeneous graph comprising 2,325 prescriptions with 464 symptoms, 414 acupoints, and 26 acupoint properties. It also presents the HyPoHGF algorithm, which leverages subgraph aggregation and a hybrid pooling mechanism to effectively recommend acupuncture prescriptions based on symptom sets.

The complete code and dataset will be made publicly available following the publication of the relevant paper.
